# Migrating to studion/core v5

## Breaking change

`studion/core` v5 requires Node.js 22 or newer for its Node-oriented commands and jobs. Upgrade and validate the execution environment before changing the orb reference to `studion/core@5.0.0`.

Consumers already running Node.js 22 or newer do not need to change their runtime.

## Affected usage

The requirement applies to:

- `core/ensure_pkg_manager`
- `core/install_dependencies`
- `core/run_script`
- `core/install_and_run`
- `core/node` or `core/node_secrets` executors pinned to a Node.js version below 22 when they run an affected command
- Custom Docker images and machine executors that run an affected command

`core/install_infisical` is not Node-oriented and is not affected by this runtime requirement.

## Migration steps

1. Locate every use of the affected commands and job.
2. Run `node -v` in each affected execution environment.
3. Upgrade environments using Node.js 18 or 20 to Node.js 22 or newer.
4. Validate the runtime change while still using `studion/core` v4.
5. Change the orb reference to `studion/core@5.0.0`.
6. Run the pipeline again and resolve any remaining failures before rollout.

Upgrading the runtime first separates Node.js or application compatibility issues from the orb upgrade.

## Configuration examples

### `core/node` executor

Before:

```yaml
executor:
  name: core/node
  tag: "20"
```

After:

```yaml
executor:
  name: core/node
  tag: "22"
```

### `core/node_secrets` executor

Before:

```yaml
executor:
  name: core/node_secrets
  tag: "20"
```

After:

```yaml
executor:
  name: core/node_secrets
  tag: "22"
```

### `core/install_and_run` job

Before:

```yaml
- core/install_and_run:
    node_tag: "20"
    pkg_manager: pnpm
    script: test
```

After:

```yaml
- core/install_and_run:
    node_tag: "22"
    pkg_manager: pnpm
    script: test
```

### Custom Docker executor

Before:

```yaml
docker:
  - image: cimg/node:20
```

After:

```yaml
docker:
  - image: cimg/node:22
```

For a machine executor, install and select Node.js 22 or newer before invoking an affected command.

## Failure diagnostic

An affected command running with an older Node.js version fails with:

```text
At least Node.js v22 is required!
```

The environment must provide `node` on `PATH`, and `node -v` must return a standard version such as `v22.20.0`.

## Validation checklist

- [ ] `node -v` reports v22 or newer in every affected job.
- [ ] No affected executor, custom image, or machine environment remains pinned to Node.js 18 or 20.
- [ ] The pipeline passes on `studion/core` v4 after upgrading the runtime.
- [ ] The orb reference is updated to `studion/core@5.0.0`.
- [ ] The pipeline passes with `studion/core` v5.
